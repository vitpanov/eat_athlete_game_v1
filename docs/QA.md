# Проверка проекта

## Базовая проверка переноса

В распакованной папке:

```sh
npm run check
npm run dev
```

В проверку `check` входят синтаксис JavaScript и 14 автоматических тестов модели. Не требуется npm install или доступ к сторонним сервисам. На момент создания архива использовался Node.js 24.22.1.

Исходные файлы `dist/`, тесты и `.openai/hosting.json` сверены побайтно с опубликованным коммитом. Проверен запуск автономного HTTP-сервера, раздача HTML/JS/CSS/SVG, отсутствие выдачи корневой документации/настроек, ответ 404 для неизвестного файла и запрет POST. Архив дополнительно распакован для повторной проверки целостности и запуска.

## Что покрывают 14 тестов

1. Четыре дела и бесплатная вода.
2. Однократная награда за баланс дня.
3. Блокировка тренировки при недостатке еды/воды без частичного изменения состояния.
4. Усталость снижает прирост; отдых возвращает эффективность.
5. Сытый и напоенный сон эффективнее; начало следующего дня.
6. Однократная покупка и влияние снаряжения.
7. Стоимость/частота клубного десерта.
8. Дата старта и минимальные показатели допуска.
9. Один гель на гонку.
10. Однократная запись результата и открытие следующей дистанции.
11. Сход при агрессивном темпе и слабом состоянии.
12. Достижимость всех четырёх финишей при сбалансированном плане.
13. Сериализация/восстановление модели, включая активную гонку.
14. Диапазоны показателей после длинной последовательности действий.

Они не проверяют весь DOM, браузерную анимацию, реальный localStorage или физический телефон.

## Чек-лист ручного прогона

Используй отдельный профиль/сохранение для тестов, сохрани прогресс игрока до экспериментов.

- [ ] Новый вход: имя, начало игры, закрытие приветствия.
- [ ] Нажать на атлета; выключить/включить анимацию и звук.
- [ ] По одной тренировке каждого типа; сравнить Easy и Hard.
- [ ] Вода не тратит действие; четвёртой бесплатной фляги нет.
- [ ] Еда + вода + тренировка дают ровно один бонус.
- [ ] Десерт списывает 15 и недоступен повторно в тот же день.
- [ ] Израсходовать четыре дела, выспаться; проверить новый день.
- [ ] Купить предмет и костюм; обновить страницу и проверить сохранение.
- [ ] К дню 7 восстановить показатели и выйти на старт.
- [ ] Менять темп, применить гель один раз, поставить на паузу.
- [ ] Свернуть/вернуть вкладку, затем перезагрузить во время гонки.
- [ ] Финиш: время, сплиты, однократная награда, следующая дистанция.
- [ ] Сход: результат, награда опыта и повторный старт через три дня.
- [ ] Приглашение друзей и отправка результата.
- [ ] Экран 360 / 390 / 430 px и широкий экран; нет горизонтальной прокрутки.
- [ ] Safari iOS и Chrome Android на реальном устройстве.
- [ ] Клавиатура, фокус, Escape, уменьшение движения, крупный системный шрифт.
- [ ] Нехватка/блокировка localStorage; сохранение не теряется молча.
- [ ] Две вкладки с одним origin: поведение явно определено.

Обнаруженные проблемы записывать с устройством, браузером, шагами, ожидаемым и фактическим результатом. Не считать UI-проверку выполненной только по прохождению модельных тестов.

# Продолжить игру в Codex с телефона

Код проекта: https://github.com/vitpanov/eat_athlete_game_v1

Играть и отправлять друзьям: https://sedobnaya-atletika.vitpanov.chatgpt.site/

## Один раз настроить Codex Cloud

Первичную настройку нового окружения выполняют в веб-версии Codex или в настольном приложении. Для работы только с телефона открой веб-версию в браузере. В мобильном интерфейсе Codex можно запускать задачи в уже опубликованном окружении.

1. Открой Codex в браузере под своим аккаунтом ChatGPT.
2. В новой задаче выбери **Work in → Cloud → Select environment → Create environment**. Другой путь: **Settings → Codex Cloud → Environments → Create environment**.
3. Выбери **vitpanov/eat_athlete_game_v1**, основная ветка — **main**. Если репозиторий не виден, проверь подключение GitHub и доступ Codex к этому конкретному репозиторию.
4. Нажми **Get started**. Для проекта нужен **Node.js 22+**; установка npm-зависимостей не требуется. Попроси агент выполнить **npm run check** и настроить предпросмотр через **npm run dev**. Если окружение требует другой порт или сетевой интерфейс, агент может задать `TRIBUDDY_PORT` и `TRIBUDDY_HOST`.
5. Проверь отчёт о настройке и нажми **Publish**. После **Environment published** нажми **Start a new task**.
6. В первой задаче напиши: **Прочитай START_IN_CODEX.txt и выполни описанный там стартовый проход. Я работаю только с телефона.**

Здесь Publish сохраняет окружение для задач Codex. Это отдельное действие от публикации самой игры для друзей.

В дальнейшем выбирай это окружение в Codex и описывай нужные изменения обычным сообщением. Ту же задачу можно продолжить с другого устройства. Принятые изменения сохраняй в GitHub; сохранённое окружение не заменяет историю кода.

Официальная инструкция: [Codex Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environments). Проверено 27.10.2026. Доступность пунктов интерфейса может зависеть от аккаунта и развёртывания функции.

## Что агент должен знать сразу

- Здесь уже рабочая beta, а не пустой шаблон. Контекст находится в `AGENTS.md` и `docs/HANDOFF.md`.
- `dist/` содержит редактируемый исходный код. Команды сборки нет.
- Проверка: `npm run check` — синтаксис и 14 тестов модели.
- Запуск: `npm run dev`. По умолчанию сервер слушает `127.0.0.1:5173` внутри окружения; для телефона нужна ссылка предпросмотра, которую выдаёт среда Codex.
- Баланс: `npm run inspect:balance` воспроизводит подтверждённую проблему прогрессии.
- Аккаунты, токены и API-ключи для запуска игры не нужны.
- GitHub пока не публикует изменения на игровой сайт автоматически. Дальнейшая публикация описана в `docs/DEPLOYMENT.md`.

## Альтернатива при работе на компьютере

Открой корень этого репозитория, где находятся `package.json` и `AGENTS.md`, в Codex. Дай агенту прочитать `START_IN_CODEX.txt`.

Для самостоятельного запуска нужен Node.js 22+:

```sh
npm run check
npm run dev
```

Открой http://127.0.0.1:5173/. Установка зависимостей и сборка не нужны. Не открывай `dist/index.html` через `file://`: браузер ограничивает ES-модули.

## Что переносится

В репозитории находятся код игры и графики, тесты, правила, ограничения, контекст и данные существующего Sites-проекта. Сохранения игроков остаются в их браузерах и не входят в перенос. На другом домене сохранение автоматически не появляется. Доступ к хостингу также не передаётся вместе с файлами.

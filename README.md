# Съедобная атлетика — триатлет на подкормке

Мобильная браузерная игра-тамагочи для сообщества «Съедобная атлетика».
Плыви. Крути. Беги. Ешь. От первого спринта до 226 км.

**Начни с [START_HERE.md](START_HERE.md).** Готовый запрос для Codex — [START_IN_CODEX.txt](START_IN_CODEX.txt).

Публичная beta: https://sedobnaya-atletika.vitpanov.chatgpt.site/

Репозиторий для продолжения разработки: https://github.com/vitpanov/eat_athlete_game_v1

Владелец работает с телефона. Основной путь — подключить этот репозиторий к Codex Cloud и дать агенту прочитать `START_IN_CODEX.txt`. Скачивать архив и запускать терминал на телефоне не требуется. Команды ниже выполняет Codex в облачном окружении или разработчик на компьютере.

## Быстрый запуск

Нужен Node.js 22 или новее. Пакет проверен на Node.js 24.22.1.

```sh
npm run dev
```

Открой http://127.0.0.1:5173/ в браузере. Установка зависимостей и сборка не нужны.
После изменения файлов обнови страницу. Остановить сервер: Ctrl+C.

```sh
npm run check
npm test
npm run inspect:balance
```

`check` проверяет синтаксис и запускает 14 тестов. `inspect:balance` воспроизводит найденную особенность баланса; это диагностический сценарий, а не требование сохранить текущее поведение.

| `docs/HANDOFF.md` | Контекст, договорённости и состояние проекта |
| `docs/GAME_RULES.md` | Цифры, правила и экономика текущей версии |

**Важно для разработки:** `dist/` здесь содержит редактируемые исходники. Это не автоматически создаваемая папка сборки. Не удаляй её перед «build».

## Сохранения

Ключ `localStorage`: `tribuddy-v1`. У каждого браузера и адреса сайта свой прогресс.
Аккаунтов, сервера игроков и общего рейтинга сейчас нет. Смена домена/порта не переносит сохранение. Перенос самих сохранений — отдельная задача.

## Состав переноса

Файлы игры в `dist/`, исходные 14 тестов и `.openai/hosting.json` скопированы из опубликованного коммита без изменений. В пакет добавлены переносимый запуск и документация; обновлён `package.json`.

Исходный архив не содержит `.git`, токенов, пользовательских сохранений и зависимостей среды ChatGPT. В GitHub перенесено его содержимое с обновлёнными инструкциями для телефона; оригинальный ZIP остаётся самостоятельным снимком. Публичный сайт переносом кода не изменяется. Автоматическая публикация из GitHub пока не настроена.

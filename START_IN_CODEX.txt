Продолжаем существующую игру «Съедобная атлетика — триатлет на подкормке» из этой папки. Это тамагочи про триатлета для нашего сообщества; главный экран и управление должны быть удобны на телефоне. Публичную ссылку отправляем друзьям для тестирования.

Я работаю только с телефона через Codex Cloud. Репозиторий: https://github.com/vitpanov/eat_athlete_game_v1. Команды запуска и проверки выполняй сам в окружении, а мне давай доступную ссылку предпросмотра и понятный результат. Не делай установку программы или распаковку архива на компьютере обязательным шагом.

Прочитай AGENTS.md, README.md, docs/HANDOFF.md, docs/KNOWN_ISSUES.md и docs/QA.md. Не создавай игру заново: здесь уже лежит рабочая beta, включая графику, игровые механики и 14 тестов.

Сначала запусти npm run check, затем npm run dev. Если твоя среда имеет обязательный способ предпросмотра, следуй ему и укажи фактический адрес. Осмотри мобильный интерфейс, если браузер доступен. При ограничениях среды не выдавай автоматические тесты за проверку на реальном телефоне.

Кратко сообщи, что проект принят и запускается, перечисли подтверждённые проблемы и предложи три приоритетных улучшения для следующего этапа. Особое внимание — балансу прогрессии, сохранениям и удобству игры одной рукой. Диагностический сценарий слабого баланса: npm run inspect:balance. Предложения в backlog ещё не означают, что все функции нужно реализовать сразу.

Сохраняй интеграцию «Съедобной атлетики», клубный юмор и русскоязычный интерфейс с небольшими понятными английскими подписями. Сохранения текущих игроков не сбрасывай. Не переезжай на новый стек без необходимости. Публичный сайт и способ публикации описаны в docs/DEPLOYMENT.md; перенос файлов сам по себе не даёт доступа к аккаунту хостинга.
